- **AI** — Autonomous agents, LLM orchestration & automation architectures
- **WEB** — High-performance full-stack web engineering & spatial experiences
- **DESIGN** — Awwwards-tier UI/UX, kinetic motion & design systems
- **PITCH** — Stage persuasion, high-stakes storytelling & judge engagement
- **SELL** — Product positioning, market distribution & growth mechanics

---

## 🛠️ Tech Stack & Libraries
- **Core**: HTML5, CSS3 Custom Properties, Modern JavaScript (ES6+)
- **Typography**: Space Grotesk, Syne, Inter, JetBrains Mono
- **Motion & Scrolling**: GSAP 3, ScrollTrigger, Lenis Smooth Scroll
- **Iconography**: Lucide Icons
- **Audio Synthesis**: Web Audio API Haptic Audio & Drone Synthesizer

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using VS Code Live Server or Python HTTP Server:
python -m http.server 3000
```
Visit `http://localhost:3000` to view the website.
